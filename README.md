## 🇬🇧 English

Complete native Russian language localization pack for DeepSeek Harness Web UI and settings cards.

### Features

- **Core UI Coverage**: Complete Russian dictionaries for session menus, agent controls, and system settings.
- **Native Selector**: Integrates directly into DSH Settings → General → Language.
- **Namespace Isolation**: Compatible alongside third-party plugin locale bundles.

### Install

```bash
dsh plugin --profile web add @goodandready/dsh-russian-lang
```
