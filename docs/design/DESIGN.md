# DESIGN.md — @goodandready/dsh-russian-lang

## Product / Purpose
- **Назначение**: Официальный плагин русской локализации, умной экранной типографики, исправления раскладки и языковой адаптации веб-интерфейса DeepSeek Harness (DSH v0.1.5-alpha.1+).
- **Аудитория**: Русскоязычные инженеры, разработчики и пользователи DSH, работающие с ИИ-моделями в терминале и браузере.
- **Статус**: В активной разработке (v0.2.7 выпущен, готовится ветка v0.2.8 / smart-ux).

## User Surfaces
- **DSH UI / settings / slots**:
  1. `settings.plugin.item`: Карточка настроек плагина во вкладке «Настройки → Плагины → Настройки плагинов» (`key: 'russian-lang'`).
  2. `conversation.session.header.utilities`: Быстрый переключатель языка `RU ⇄ EN` в один клик в шапке активной сессии.
  3. `conversation.input.right`: Индикатор текущей раскладки (`RU` / `EN`) в правом углу панели ввода сообщений.
  4. `conversation.chat.assistant-actions`: Кнопка «Перевести на русский» в тулбаре действий над ответом ассистента.
- **Web / Chat Composer**:
  - Живая типографика в реальном времени (`""` → `«»`, `--` → `—`, `...` → `…`, неразрывные пробелы после предлогов `в `, `на `, `с ` и др.).
  - Переключение раскладки <kbd>Alt+L</kbd> и транслитерация <kbd>Alt+T</kbd>.
  - Русские алиасы слэш-команд (`/цель`, `/сжать`, `/план`, `/экспорт`, `/память`, `/отзыв`, `/разрешения`).
- **Export & Reports**:
  - Локализованный экспорт сессии в Markdown с русскими датами, статусами этапов, статистикой токенов и задержек.
- **API / Cordis Host Services**:
  - Настройки схемы `russian-lang` (типографика, буква «ё», стиль системного промпта, переопределения).
  - Инъекция секции системного промпта `dsh-russian-lang-agent-prompt`.

## Visual Direction
- **Атмосфера**: Минималистичный, высокоточный интерфейс разработчика (Swiss precision + dark graphite theme).
- **Принципы**: Нативная интеграция без визуального шума. Никаких всплывающих баннеров, перекрывающих рабочую область. Плавные переходы, ненавязчивые статус-чипы.
- **Не копировать**: Чужие логотипы, сторонние библиотеки стилей, жестко зашитые цвета.

## Foundations
- **Цвета и роли**: Исключительно системные CSS-переменные DSH:
  - Фон: `var(--dsw-alias-bg-layer-3)` и `var(--dsw-alias-bg-layer-2)`
  - Границы: `var(--dsw-alias-border-l2)`
  - Основной текст: `var(--dsw-alias-label-primary)`
  - Вторичный текст: `var(--dsw-alias-label-secondary)`
  - Третичный текст / иконки: `var(--dsw-alias-label-tertiary)`
- **Типографика**: Системный шрифт интерфейса DSH (`font: inherit`), 15px для заголовков, 13px для подписей, 12px для примечаний.
- **Сетка и отступы**: Карточка 12px border-radius, отступы 14x16px, компактные чипы 24px высотой с 6px скруглением.
- **Изоляция стилей**: Префикс `rl-` у всех классов, атрибут `<style data-plugin="@goodandready/dsh-russian-lang" data-plugin-css="rl-card">`.

## Components And States
- **SettingsCard**:
  - Свёрнута по умолчанию (`aria-expanded`).
  - Состояния снимка: `loading` (спиннер/скелетон), `unavailable` (блокировка с предупреждением), `ready` (активная форма).
  - Переключатели: активность перевода, типографика, буква «ё», выбор пресета системного промпта (Технический эксперт / Технический писатель / Лаконичный).
- **QuickLanguageSwitcher**:
  - Компактный чип `RU` / `EN` в шапке сессии (`header.utilities`). При клике мгновенно переключает `runtime.setLocale`.
- **InputLayoutIndicator & AutoTypo**:
  - Ненавязчивый бейдж языка ввода в composer.
  - Автоматическая подстановка кавычек-ёлочек и длинных тире без задержки ввода.
- **TranslateTurnAction**:
  - Кнопка с иконкой языка в тулбаре реплики.

## User Flows
- **Сценарий 1: Быстрое переключение языка**
  Пользователь нажимает на чип `RU` в шапке диалога -> язык мгновенно меняется на `EN` без перезагрузки и без перехода в Настройки.
- **Сценарий 2: Набор текста с умной типографикой**
  Пользователь печатает в поле ввода `"Привет"` -> текст мгновенно форматируется в `«Привет»`.
- **Сценарий 3: Набор команды на русском**
  Пользователь вводит `/цель` -> подставляется или выполняется `/goal`.
- **Сценарий 4: Экспорт сессии на русском**
  Пользователь экспортирует диалог -> формируется аккуратный Markdown с русскими заголовками, датами и статусами.

## Do / Don't
- **Do**:
  - Использовать только CSS-переменные темы.
  - Очищать слушатели событий клавиатуры и DOM в `ctx.effect`.
  - Обеспечивать обратную совместимость со старыми и новыми версиями DSH.
- **Don't**:
  - Не добавлять отдельный раздел в главный боковой список (только карточка настроек и чипы в слотах).
  - Не ломать ввод кода и обратных кавычек (типографика не должна портить блоки кода ``` или `code`).
  - Не блокировать рендеринг страницы при отсутствии сервисов ядра.

## Locked Design Decisions
- **2026-09-07** — Настройки плагина размещаются карточкой в `settings.plugin.item`, а не отдельной боковой вкладкой; причина — сохранение компактности бокового меню ядра.
- **2026-09-08** — Быстрый переключатель языка размещается в `conversation.session.header.utilities`, чтобы быть всегда доступным в один клик без перехода в Настройки.
- **2026-09-08** — Типографика на лету не форматирует содержимое внутри бэктиков (inline code и code blocks).
