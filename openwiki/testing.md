# Тестирование и контроль качества

## Запуск тестового набора

Вся проектная работа сопровождается обязательным прогоном тестов:

```bash
# 1. Запуск полных Node.js и Python тестов
npm test

# 2. Полная механическая проверка шлюзов качества
npm run check
```

## Состав проверок `npm run check`

Шлюз качества `npm run check` включает 6 обязательных этапов:
1. `python3 build.py --check`: валидация сборки бандла, синтаксиса и размера (< 160 KiB).
2. `python3 tools/lint_translations.py`: линтинг словарей, проверка экранирования, кавычек и структуры JSON.
3. `python3 check-coverage.py`: проверка 100% покрытия ключей ядра и установленных плагинов.
4. `python3 tools/term_check.py --ci`: проверка соответствия терминологии каноническому глоссарию `glossary.json`.
5. `python3 tools/check_pack_size.py`: контроль размера архива пакета для соответствия лимиту DSH Store (< 256 KiB).
6. `python3 tools/check_data_integrity.py`: строгая проверка целостности `supported-inventory.json`, диапазонов `compatible_range`, снапшотов и отсутствия дрейфа версий.
