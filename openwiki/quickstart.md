# Быстрый старт

## Описание проекта

`@goodandready/dsh-russian-lang` — официальный плагин русской локализации ядра DeepSeek Harness (DSH) и всех совместимых плагинов экосистемы. Плагин перехватывает запросы локализации в клиентском runtime (`LocaleRuntime`), инжектирует русские словари и обеспечивает 100% покрытие интерфейса без модификации чужого кода.

## Системные требования

- **Node.js**: >= 20.0.0
- **DeepSeek Harness Core**: v0.2.0-rc.2 (диапазон совместимости: `>=0.2.0-rc.1 <0.3.0`)
- **Cordis framework**: совместимый рантайм DSH

## Установка плагина

Установка выполняется через штатную команду DSH в рабочий профиль (например, `web`):

```bash
dsh plugin --profile web add @goodandready/dsh-russian-lang
```

После завершения установки перезапустите веб-службу DSH:

```bash
systemctl --user restart dsh-web.service
```

## Горячие клавиши и управление

- `<kbd>Alt+L</kbd>`: быстрое переключение между русской и английской/исходной локалями интерфейса.
- Индикатор раскладки в строке ввода: автоматически подсвечивает текущий язык ввода.
- Настройки плагина доступны в разделе **Настройки → Плагины → Русская локализация (dsh-russian-lang)**.
