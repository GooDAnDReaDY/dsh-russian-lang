# Конфигурация плагина

## Схема настроек (`cordis.patch.yml`)

Плагин регистрирует карточку настроек с реактивными полями:

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `translateEngine` | string | `'off'` | Движок автоматического доперевода: `'off'`, `'local'`, `'google'` |
| `autoLayoutIndicator` | boolean | `true` | Индикатор текущей раскладки клавиатуры в поле ввода |
| `typographyEnhance` | boolean | `true` | Типографика на лету (кавычки-ёлочки, неразрывные пробелы, длинные тире) |
| `bilingualPalette` | boolean | `true` | Двуязычный поиск в командной палитре (на русском и английском) |
| `russianAltL` | boolean | `true` | Горячая клавиша `<kbd>Alt+L</kbd>` для переключения языка |
| `inspectDom` | boolean | `false` | Инструмент подсветки непереведённых строк интерфейса (для QA) |

## Защита от записи в readonly режиме

Клиентская часть проверяет флаг `snapshot.writable`:
- Если `snap.writable === false`, интерактивные контролы переводятся в режим `disabled` с подсказкой пользователю.
- Все операции сохранения оборачиваются в `safeSet()` с перехватом возможных ошибок `scope.set()`, исключая ложные сообщения об успешном сохранении.
