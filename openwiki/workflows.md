# Регламент разработки и каналы поставки

## Разработка на MiniAI

- Вся разработка ведётся исключительно на сервере MiniAI (`192.168.1.111`) под учётной записью `vadim`.
- Git-операции в среде разработки выполняются через авторизованный враппер соответствующего агента (например, `/home/vadim/.ssh/bin/git-codex`, `git-opencode`, `git-antigravity` и т.д.) либо через переменную окружения `GIT_BIN`, обеспечивающую корректную аутентификацию в Gitea. Для человека-разработчика допустим штатный `git` с настроенным SSH-ключом доступа.
- Базовый репозиторий: `goodandready/dsh-russian-lang` в Gitea.
- Корневой DEV-каталог `/mnt/external/Project/DEV/dhsplugins/dsh-russian-lang` находится на ветке `main` и синхронизируется только fast-forward.
- Разработка ведётся в изолированных Git worktrees: `.worktrees/<branch>`.

## Трёхканальная изоляция артефактов

Проект строго разделяет три канала поставки:

1. **Gitea (внутренняя разработка)**:
   - Полная история коммитов, ветки, PR, issues.
   - Внутренняя документация: `AGENTS.md`, `index.md`, `openwiki/**`, `docs/**`, `supported-inventory.json`, `.gitea/**`.

2. **GitHub Mirror (публичная витрина)**:
   - Публикация выполняется исключительно через скрипт `scripts/publish-github.sh --push <tag>`.
   - В репозиторий отправляются только обезличенные продуктовые коммиты и релизные теги.
   - Все внутренние документы, инструкции агентов, открытая вики (`openwiki/**`), служебные скрипты и конфиги CI исключены из публичного дерева.

3. **npm registry (пакет для пользователей)**:
   - Состав пакета формируется строго по полю `files` в `package.json`.
   - Включает только скомпилированный `lib/client.js`, `lib/index.js`, словари, `glossary.json`, `README.md`, `LICENSE`.
   - Перед публикацией обязательно валидируется через `npm pack --dry-run`.
